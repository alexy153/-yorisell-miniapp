# Админ-панель

Открывается из Telegram по ссылке владельца `t.me/Yorisell_bot/admin`. Сервер пускает только владельца. Открыть страницу в обычном браузере можно, но данных она не покажет.

## Товары

- **Переключатель справа** — показывать товар в каталоге. Скрытый товар пропадает из каталога и из карточки, в списке помечен «скрыт».
- **Изменить** — название, описание, категория, замеры, статус и обложка.
  - Замеры пустые — покупатель видит «Замеры в ЛС».
  - Статус «Как в канале» — решение берётся из поста SOLD. «В наличии» снимает отметку из канала. «Продано» скрывает товар.
  - Обложка — любое фото этого товара. «Первое фото» — вернуть по умолчанию.
- **Обновить** — перечитать один пост из канала, если вы поправили его в Telegram.
- **Стрелки ↑ ↓** — порядок показа в каталоге. Порядок сохраняется сразу.
- **Обновить каталог** — перечитать канал сейчас: новые посты, правки и отметки SOLD. Пока архив не загружен, каждое нажатие продвигает его дальше.

Ручные правки названия, описания и категории синхронизация не перезаписывает. Статус и обложку тоже.

## Статистика

- Периоды: «Сегодня», «7 дней», «Всё».
- Визиты, открытия карточек, нажатия «Забронировать» и ♡, топ товаров по открытиям.
- Личных данных не собирается: только числа по дням и по товарам.
