# Yorisell — Telegram Mini App

Каталог магазина Yorisell внутри Telegram: что есть в наличии, карточки товаров и бронирование через личку продавца. Товары берутся из публичного канала @Yorisell, владелец правит их в админке.

## Структура

- `web/` — приложение покупателя (статика): каталог, карточка товара, избранное, «Инфо». Открывается и в Telegram, и в обычном браузере.
- `web/admin/` — админ-панель владельца: товары, порядок, правки, обложка, статистика.
- `worker/` — сервер на Cloudflare Workers: API, проверка подписи Telegram, синхронизация с каналом, миграции базы D1 (`worker/migrations/`).
- `scripts/` — локальный сервер для разработки и встроенная SQLite-база с тем же интерфейсом, что у D1.
- `tests/` — тесты на встроенном `node:test`, без внешних библиотек. `tests/fixtures/` — сохранённые страницы канала, поэтому тесты работают без сети.
- `docs/` — выкладка и настройка BotFather (`docs/deploy.md`), работа с админкой (`docs/admin.md`).
- `wrangler.toml` — настройки Cloudflare. Секретов здесь нет.

## Запуск

Нужен Node.js 22.13 или новее: там есть встроенный SQLite. Проверено на Node 24.

```
npm test      # все тесты
npm run dev   # приложение, админка и API на http://localhost:8787
```

`npm run dev` берёт каталог из сохранённых страниц канала, без сети. Чтобы взять настоящий канал: `LIVE=1 npm run dev`. Админка локально закрыта, пока не задан `ADMIN_ID`.

## Секреты

Токен бота и ID администратора не лежат в репозитории. Они задаются секретами Worker в настройках Cloudflare: `BOT_TOKEN` и `ADMIN_ID` (см. `docs/deploy.md`). Файлы `.env`, `.dev.vars`, папка `data/` (локальная база) и `.wrangler/` есть в `.gitignore`. Тест `tests/no-secrets.test.js` проверяет, что токена бота нет ни в одном файле репозитория.

## Доступ администратора

Админские маршруты принимают только заголовок `Authorization: tma <initData>` с подписью Telegram. Сервер проверяет подпись токеном бота и только потом сравнивает ID пользователя с `ADMIN_ID`. Без подписи ответ 401, с неверной, чужой или устаревшей подписью — 403. Тесты: `tests/router.test.js`, `tests/api.test.js`.

## Лимиты бесплатного тарифа

Cloudflare на бесплатном тарифе разрешает до 50 обращений к базе и к сети на один запуск Worker. Синхронизация укладывается в 40 обращений: повторный запуск без изменений только читает, новые товары пишутся порциями, архив догружается между запусками. Фото скачиваются при первом показе и хранятся в базе. Тест `tests/sync.test.js` проверяет, что архив догружается при маленьком бюджете и не выходит за него.

## Что уже есть

- Синхронизация с каналом: товары, пометки SOLD, ручные правки владельца не перезаписываются.
- Каталог без скрытых и проданных товаров: плитки категорий сверху и поиск по названию.
- Избранное: хранится в облаке Telegram и в памяти браузера. Проданные товары остаются с пометкой «Нет в наличии».
- Бронирование: ссылка открывает личку продавца с готовым текстом. Данные покупателя приложение не собирает.
- Счётчики без личных данных: показы, открытия, бронирования, избранное.
- Админка: переключатель видимости, статус «продано», порядок стрелками, правка названия, описания, категории, замеров и обложки, обновление одного товара и всего каталога, статистика за сегодня, 7 дней и всё время.
