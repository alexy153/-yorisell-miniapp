# Выкладка и настройка

Всё работает на бесплатных тарифах: приложение и сервер — Cloudflare (Workers и статика), база — D1, код — этот репозиторий. Свой сервер не нужен.

## Что понадобится

- Аккаунт Cloudflare (бесплатный).
- Node.js 22.13 или новее на компьютере, с которого выкладываете.
- Токен бота @Yorisell_bot (BotFather → `/token`).
- Ваш числовой Telegram ID (он нужен как ADMIN_ID).

Токен и ID не записываются ни в файлы, ни в переписку. Они задаются секретами Cloudflare (шаг 3).

## 1. Войти и создать базу

```
npx wrangler login
npx wrangler d1 create yorisell
```

Вторая команда выведет `database_id`. Вставьте его в `wrangler.toml` вместо `ЗАМЕНИТЕ-НА-ID-ИЗ-wrangler-d1-create`. Сам ID секретом не является.

## 2. Создать таблицы

```
npx wrangler d1 migrations apply yorisell --remote
```

## 3. Передать секреты

```
npx wrangler secret put BOT_TOKEN
npx wrangler secret put ADMIN_ID
```

Команды попросят ввести значение. Не вставляйте его в файлы, коммиты и чат.

## 4. Выложить

```
npx wrangler deploy
```

Адрес будет вида `https://yorisell.<ваш-поддомен>.workers.dev`. Проверка: откройте `/api/health`, должно быть `{"ok":true}`.

Можно и без терминала: подключите репозиторий в панели Cloudflare через Git-интеграцию, командой деплоя укажите `npx wrangler deploy`. Секреты из шага 3 при этом всё равно задаются отдельно.

## 5. Первая загрузка каталога

Синхронизация читает канал порциями: один запуск делает не больше 40 обращений к Cloudflare (лимит бесплатного тарифа — 50). Поэтому полный архив загружается за несколько запусков.

- Расписание запускает обновление каждые 30 минут и продолжает архив с того места, где остановилось.
- Чтобы ускорить, откройте админку и нажимайте «Обновить каталог», пока в примечании над списком есть фраза про догрузку архива.

## 6. Открыть приложение из Telegram (BotFather)

Адрес ниже — ваш из шага 4.

Покупатели:
1. `/newapp` → выбрать @Yorisell_bot → название, описание, фото (`web/assets/logo.jpg`).
2. Адрес приложения: `https://<ваш-адрес>/`. Короткое имя: `shop`. Итоговая ссылка: `t.me/Yorisell_bot/shop`.
3. `/setmenubutton` → @Yorisell_bot → адрес `https://<ваш-адрес>/`, подпись «Каталог».

Владелец:
1. `/newapp` → @Yorisell_bot → название «Админка».
2. Адрес: `https://<ваш-адрес>/admin/` (с косой чертой на конце). Короткое имя: `admin`. Ссылка: `t.me/Yorisell_bot/admin`.

Ссылку админки не публикуйте. Сервер и так пускает в неё только владельца, но покупателям она ни к чему.

## 7. Проверка

- `t.me/Yorisell_bot/shop` открывает каталог с товарами в наличии.
- `t.me/Yorisell_bot/admin` с аккаунта владельца показывает список товаров.
- Адрес админки в обычном браузере показывает «Откройте админку в Telegram». Значит, без Telegram доступа нет.
- Если в админке «Нет доступа» при верном аккаунте, проверьте `ADMIN_ID`. Если сессия устарела, закройте приложение и откройте снова.

## Обновления

- Новый код: `git pull`, затем `npx wrangler deploy`.
- Новые таблицы (новая миграция в `worker/migrations/`): `npx wrangler d1 migrations apply yorisell --remote`.
- Если новый секрет не подхватился, выполните `npx wrangler deploy` ещё раз.
