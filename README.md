# Yorisell — Telegram Mini App

Каталог магазина Yorisell внутри Telegram: что есть в наличии, карточки товаров и бронирование через личку продавца. Товары берутся из публичного канала @Yorisell, владелец правит их в админке.

## Структура

- `web/` — приложение покупателя (статика): каталог, карточка товара, избранное, «Инфо». Открывается и в Telegram, и в обычном браузере.
- `worker/` — сервер на Cloudflare Workers: API, проверка подписи Telegram, синхронизация с каналом, миграции базы D1 (`worker/migrations/`).
- `scripts/` — локальный сервер для разработки и встроенная SQLite-база с тем же интерфейсом, что у D1.
- `tests/` — тесты на встроенном `node:test`, без внешних библиотек. `tests/fixtures/` — сохранённые страницы канала, поэтому тесты работают без сети.

## Запуск

Нужен Node.js 22.13 или новее: там есть встроенный SQLite. Проверено на Node 24.

```
npm test      # все тесты
npm run dev   # приложение и API на http://localhost:8787
```

`npm run dev` берёт каталог из сохранённых страниц канала, без сети. Чтобы взять настоящий канал: `LIVE=1 npm run dev`.

## Секреты

Токен бота и ID администратора не лежат в репозитории. Они задаются секретами Worker в настройках Cloudflare: `BOT_TOKEN` и `ADMIN_ID`. Файлы `.env`, `.dev.vars`, папка `data/` (локальная база) и `.wrangler/` есть в `.gitignore`. Тест `tests/no-secrets.test.js` проверяет, что токена бота нет ни в одном файле репозитория.

## Доступ администратора

Админские маршруты принимают только заголовок `Authorization: tma <initData>` с подписью Telegram. Сервер проверяет подпись токеном бота и только потом сравнивает ID пользователя с `ADMIN_ID`. Без подписи ответ 401, с неверной, чужой или устаревшей подписью — 403. Локально `ADMIN_ID` не задан, поэтому админка закрыта. Тесты: `tests/router.test.js`, `tests/api.test.js`.

## Что уже есть

- Синхронизация с каналом порциями: фото скачиваются на сервер, пометка SOLD, скрытие и ручные правки владельца не перезаписываются.
- Каталог без скрытых и проданных товаров: плитки категорий сверху и поиск по названию.
- Избранное: хранится в облаке Telegram и в памяти браузера. Проданные товары остаются с пометкой «Нет в наличии».
- Счётчики без личных данных: показы, открытия, бронирования, избранное.
- Бронирование: ссылка открывает личку продавца с готовым текстом. Данные покупателя приложение не собирает.
