# Yorisell — Telegram Mini App

Каталог магазина Yorisell внутри Telegram: актуальное наличие, карточки товаров и бронирование через личку продавца.

## Структура (план)

- `web/` — приложение: статические файлы для Cloudflare Pages.
- `worker/` — сервер на Cloudflare Workers: API, админ-панель, синхронизация с каналом, база D1.
- `tests/` — тесты на встроенном `node:test`, без внешних библиотек.
- `docs/` — инструкции: как выложить и как обновлять.

## Секреты

Токен бота и ID администратора в репозиторий не попадают. Они задаются переменными Worker в настройках Cloudflare (`BOT_TOKEN`, `ADMIN_ID`). Локальные файлы с секретами (`.env`, `.dev.vars`) игнорируются через `.gitignore`.

## Статус

Фаза 1 сделана: проверка подписи initData и доступ к админке (401 без подписи, 403 с неверной), разбор постов канала, ссылка «Забронировать».

Запуск тестов: `npm test` (встроенный `node:test`, без внешних библиотек). Следующие фазы: импорт каталога с фото, база D1, приложение для покупателя, админ-панель.
